# Creating Users and Group Policy Objects for AD

![Status](https://img.shields.io/badge/Status-In%20Progress-blue)

## Project Overview

This project documents the creation and management of Active Directory users and groups, along with Group Policy Objects used to centrally manage Windows settings and security policies.

## Skills Demonstrated

- Active Directory Users and Computers (ADUC)
- User and group administration
- Group Policy Management
- Group Policy Objects (GPOs)
- Windows Server administration
- PowerShell
